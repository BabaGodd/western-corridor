REAL TRAIN SOUNDS - drop your audio files in this folder (next to index.html)

  train-loop.mp3      a SEAMLESS LOOP of a train running: engine rumble + rail clatter (10-60 s long)
  train-horn.mp3      ONE locomotive horn blast / double blast (played as the train nears each station)
  station-arrive.mp3  (optional) brake squeal / bell for the moment the train stops at a station

.ogg files work too (same names). If a file is missing, that sound is simply skipped.
If the folder is empty the page stays silent. Nothing synthetic is ever played.

Use recordings you are licensed to use (for example CC0 / public-domain / royalty-free for commercial use).
Keep each file under about 3 MB so the page stays quick to load.
Press M in the app to mute / unmute.
